# MEMORY — индекс памяти проекта «training-program»

Читается в начале каждой сессии. Одна строка на запись, детали — в дневных файлах.

## Что это за проект
Личная годовая программа тренировок как одностраничный сайт (`index.html`).
Открыл на телефоне → видишь тренировку на сегодня → тренируешься. Живёт на GitHub Pages:
https://maslovserg-hub.github.io/training-program/ (репо maslovserg-hub/training-program, публичный).

## Текущее состояние
- Приложение собрано, задеплоено, **PWA** (ставится на Android). Логика «сегодня» по календарю, гири 2×16, дни Пн/Ср/Пт.
- **v2 (с 2026-10-20)**: полноценное приложение — 4 вкладки со свайпом, режим тренировки с записью повторов и таймерами, история, первичная настройка, новая иконка `icons/`.
- **Дизайн**: тёмная + оранжевая тема, SVG-иконки, аккордеоны `details name="acc"`, плавные анимации (морфинг DOM), фото-атлет (гиря в шапке, бегун на день отдыха); на компьютере — вид телефона по центру.
- **Программа пересмотрена** как тренером: см. `REVIEW.md`. День B — честная нагрузка низа (присед→пистолет) + задняя цепь (RDL/Nordic) + мобилка.
