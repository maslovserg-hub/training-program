   - Анимации появления/ухода: шторки, тренировка, отдых (снизу), уведомление; шаги тренировки и онбординга въезжают сбоку.
   - **На компьютере** — «телефон» по центру по высоте окна (412×892), на телефоне без изменений.
   - Скрыты полосы прокрутки, учтён `prefers-reduced-motion`.

## Технические заметки (для быстрого входа)
- **localStorage**: `trn_start`, `trn_offset` (как раньше), `trn_log` (журнал по датам), `trn_perf` (повторы по названию варианта), `trn_rest`, `trn_sound`, `trn_vibe`, `trn_remind`, `trn_gear`, `trn_onboarded`, `trn_dismiss`, `trn_since`.
- `trn_since` — дата первого запуска v2: раньше неё тренировки не считаются пропущенными (иначе календарь показал бы десятки пропусков).
- Рендер: `render()` → `morph(el, html)`; `data-key` = идентичность блока (смена ключа → замена + анимация появления). Тикающие значения таймеров обновляет `live()` точечно, без перерисовки.
- Нельзя называть функцию `top` — конфликт с `window.top` (ловили).
- Проверка: headless Chromium/Playwright, свайпы — настоящими touch-событиями через CDP.
